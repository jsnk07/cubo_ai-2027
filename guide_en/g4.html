F4.1Data as a system

A model is only as good as the data it is trained and evaluated on. A brilliant algorithm with dirty data produces bad results with great confidence. That is why in real projects most of the time goes into the data, not the model.

Think of data as a system with stages:

  1. Capture: where it comes from, with what permission and how often.
  2. Cleaning: duplicates, missing values, inconsistent formats (dates, capitalization, units), typing errors.
  3. Structure: columns with clear meaning, correct types, a data dictionary explaining each field.
  4. Quality: does it represent all the cases and groups the system will see in reality?
  5. Versioning: knowing which version of the data produced which result.
Key ideas
  • Data quality before model architecture.
  • If a group is not in the data, the model will not know how to treat it well.
Think about itWhich data in your institution lives on paper, in loose spreadsheets or in different formats? What would it take to use it?

F4.2Machine learning from first principles

In traditional programming you write the rules. In machine learning you give the system examples with the right answer and it finds the rules. A model that predicts whether a customer will pay on time learns from thousands of past cases with their outcome.

The basic cycle:

  1. Split the data into training (to learn) and test (to measure). Never measure with the same data you trained on.
  2. Train a model: the algorithm adjusts its parameters to make as few mistakes as possible on the examples.
  3. Evaluate with the test data: accuracy, precision, recall and the confusion matrix, which shows what it confuses with what.
  4. Review the errors: in which cases does it fail? Does it fail more for some group?

Watch out for overfitting: a model that memorizes the training data gets almost everything right there and fails on new cases. If the training score is much better than the test score, it is memorizing.

Key ideas
  • Examples with answers → the model learns the rules.
  • Training and test always kept apart.
  • The confusion matrix says more than a single percentage.
Think about itA fraud detection model is 99% accurate. If only 1% of transactions are fraud, is it a good model?

F4.3Neural networks and computer vision

A neural network is a chain of layers of simple math operations. Each “neuron” multiplies its inputs by weights, adds them up and applies a function. During training, the weights are adjusted little by little to reduce the error. With many layers, the network learns increasingly abstract representations: that is deep learning.

To a computer, an image is a table of numbers: the brightness of each pixel. Networks for vision, such as convolutional ones, first learn edges, then shapes and then objects. With that you build tasks like:

  • Classification: what is in the image?
  • Detection: where is each object?
  • Segmentation: which pixels belong to what?
  • Reading text (OCR) in photos and documents.

The same F4.1 problems apply here: if the training images were taken in good light, the model may fail at night.

Key ideas
  • A neural network learns by adjusting weights to reduce error.
  • An image is a matrix of numbers; the network learns patterns on it.
Think about itWhich visual task in your environment (documents, crops, traffic, infrastructure) could be automated, and what images would you need to train it?

F4 · Self-assessmentCheck what you learned

Why split data into training and test sets?

To measure performance on cases the model has not seen; measuring on training data overestimates quality.

What is overfitting and how do you detect it?

It is when the model memorizes the training data and generalizes poorly. You see it when training performance is much better than test performance.

What does a confusion matrix show?

How many cases of each true class were classified as each predicted class, that is, which mistakes the model makes.

Name three common data cleaning problems.

Duplicates, missing values, inconsistent formats and typing errors (any three).

How does a neural network “see” an image?

As a matrix of numbers with each pixel's brightness, on which it learns patterns of edges, shapes and objects.

Technical route
Cleaning pipeline and digit classifier
  1. Open a notebook. Without installing anything, use Google Colab, or start Jupyter in Docker and go to the address the terminal prints: 
    docker run -p 8888:8888 -v "$PWD":/home/jovyan/work quay.io/jupyter/scipy-notebook
  2. Download an open-data CSV that interests you and write a clean(df) function with pandas that removes duplicates, handles missing values, normalizes dates and text, and sets types. Print how many rows each step changed.
  3. Train a classifier of handwritten digit images (included in scikit-learn): 
    from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPClassifier
from sklearn.metrics import accuracy_score, confusion_matrix
X, y = load_digits(return_X_y=True)          # 8×8-pixel images
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.25, random_state=0)
m = MLPClassifier(hidden_layer_sizes=(64,), max_iter=500, random_state=0).fit(Xtr, ytr)
print("train:", m.score(Xtr, ytr), "test:", accuracy_score(yte, m.predict(Xte)))
print(confusion_matrix(yte, m.predict(Xte)))
  4. Show three images the model misclassified and explain why you think it failed.
  5. Change the size of the hidden layer and compare training against test: does overfitting appear?
Complementary route
Quality audit of a dataset
  1. Choose an open dataset from your field (for example, from a public data portal).
  2. Write its data dictionary: each field, what it means, its type and its possible values.
  3. In a spreadsheet, count duplicates, empty cells and out-of-range values, and document each problem.
  4. Analyze representativeness: which groups, areas or periods are missing or over-represented?
  5. Propose an ML use case with that data and write which metric you would use to evaluate it and which error would be most costly.
