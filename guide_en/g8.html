Opportunity Brief · strategy/opportunity-brief.md

Problem: what happens, in one or two sentences.

User: who it happens to, with a concrete example.

Evidence: what data or testimony shows it exists.

How it is solved today: current alternatives and their shortcomings.

Why AI: which part of the problem AI solves and which it does not.

Available data: sources, quality and privacy constraints.

Success criterion: what number or result would show it works.

Riskiest assumptions: the three that, if they fail, sink the project.

Annex · 2Glossary

AgentA system that uses a model to decide steps and tools until a task is done.
APIAn interface for one program to use another's services.
AttentionTransformer mechanism that weighs which parts of the text matter.
ChunkingSplitting documents into fragments to index them.
Confusion matrixA table showing which classes a model confuses.
DockerA tool for running programs in isolated containers.
EmbeddingA numeric vector representing the meaning of a text or image.
Evaluation setCases with expected answers used to measure a system.
Few-shotIncluding a few solved examples in the prompt.
HallucinationA convincing but false or unsupported answer.
Human-in-the-loopA point where a person reviews or approves before the system acts.
LLMLarge language model.
MCPModel Context Protocol: an open standard for connecting models with tools and data.
OllamaA tool for running open models on your computer with a local API.
OverfittingWhen a model memorizes training data and fails on new cases.
Prompt injectionAn attack that hides instructions in data to divert the model.
RAGRetrieval-augmented generation: answering with retrieved documents.
TemperatureParameter that controls how varied the model's output is.
TokenA fragment of text the model processes; the basis of its cost and context.
TransformerThe neural network architecture modern LLMs are built on.
Vector databaseA store that searches by similarity of meaning between embeddings.
VibeCodingProgramming by steering an AI in natural language and reviewing what it produces.
